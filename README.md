# 🎨 NFT Marketplace

A fully decentralized NFT minting and marketplace 
platform supporting ERC-721 tokens with IPFS 
metadata storage and MetaMask integration.

## ✨ Features
- Mint ERC-721 NFTs with IPFS metadata
- List, buy and sell NFTs on-chain
- MetaMask wallet integration
- Royalty support for creators
- Event-driven frontend updates

## 🛠 Tech Stack
- Solidity ^0.8.20
- OpenZeppelin ERC-721
- Hardhat + Chai testing
- Next.js frontend
- IPFS / Pinata
- MetaMask / Ethers.js
